# 金融基础概念

## 市盈率（P/E Ratio）

市盈率（Price-to-Earnings Ratio，简称 P/E）是衡量股票估值最常用的指标之一。

**计算公式：**
市盈率 = 股票价格 / 每股收益（EPS）

**分类：**
- **静态市盈率（Trailing P/E）**：使用过去 12 个月的实际每股收益计算。
- **动态市盈率（Forward P/E）**：使用未来 12 个月的预期每股收益计算。

**解读方法：**
- 市盈率越高，通常意味着市场对公司未来增长预期较高，但也可能意味着估值过高。
- 市盈率越低，可能表示公司被低估，但也可能反映公司增长前景不佳。
- 不同行业的市盈率差异很大，科技股通常市盈率较高（20-50倍），银行股通常较低（5-15倍）。
- 应与同行业公司对比，而非跨行业比较。

**局限性：**
- 不适用于亏损公司（EPS 为负时无意义）。
- 可能被一次性收益或亏损扭曲。
- 不考虑公司的债务水平。

## 市净率（P/B Ratio）

市净率（Price-to-Book Ratio）衡量股票价格与每股净资产的关系。

**计算公式：**
市净率 = 股票价格 / 每股净资产

**解读方法：**
- P/B < 1 表示股票价格低于公司的账面价值，可能被低估。
- P/B > 1 表示市场认为公司的价值高于其账面资产。
- 适用于资产密集型行业（银行、房地产），不太适用于轻资产公司（科技、互联网）。

## 每股收益（EPS）

每股收益（Earnings Per Share）反映公司盈利能力。

**计算公式：**
EPS = (净利润 - 优先股股息) / 加权平均普通股股数

**分类：**
- **基本 EPS**：使用实际流通在外的股票数量。
- **稀释 EPS**：假设所有可转换证券（如期权、可转债）全部转换后的 EPS，通常更保守。

## 股息率（Dividend Yield）

股息率衡量投资者通过股息获得的回报率。

**计算公式：**
股息率 = 每股年度股息 / 当前股价 × 100%

**特点：**
- 高股息率的公司通常是成熟稳定的企业（如公用事业、银行）。
- 成长型公司通常不派发或少派发股息，而是将利润再投资。
- 过高的股息率可能意味着股价大幅下跌或股息不可持续。

## 市销率（P/S Ratio）

市销率（Price-to-Sales Ratio）基于公司收入而非利润进行估值。

**计算公式：**
市销率 = 市值 / 年度总收入

**适用场景：**
- 适用于尚未盈利但有收入增长的公司（如早期科技公司）。
- 弥补市盈率在亏损公司上的不足。
