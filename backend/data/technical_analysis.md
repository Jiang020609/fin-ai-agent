# 技术分析

## 什么是技术分析？

技术分析（Technical Analysis）是通过研究历史价格和成交量数据来预测未来价格走势的方法。与基本面分析不同，技术分析不关注公司的财务状况或内在价值，而是关注市场行为本身。

技术分析的三大假设：
1. **市场行为包容消化一切** — 所有信息（基本面、政治、心理）都已反映在价格中。
2. **价格以趋势方式运行** — 一旦趋势形成，倾向于延续而非反转。
3. **历史会重演** — 人类心理不会改变，过去的价格模式会在未来重复出现。

## 移动平均线（Moving Average）

### 简单移动平均线（SMA）
SMA 是过去 N 个交易日收盘价的算术平均值。

**常用周期：**
- **5 日均线（MA5）**：短期趋势，反映近一周走势。
- **20 日均线（MA20）**：中短期趋势，约一个月。
- **50 日均线（MA50）**：中期趋势。
- **200 日均线（MA200）**：长期趋势，是机构投资者常用的参考线。

### 指数移动平均线（EMA）
EMA 赋予近期数据更高的权重，对价格变化反应更灵敏。

**计算公式：**
EMA = 当日收盘价 × 平滑因子 + 昨日EMA × (1 - 平滑因子)
平滑因子 = 2 / (N + 1)

### 均线交叉信号
- **金叉（Golden Cross）**：短期均线上穿长期均线，通常被视为买入信号。经典案例为 50 日均线上穿 200 日均线。
- **死叉（Death Cross）**：短期均线下穿长期均线，通常被视为卖出信号。经典案例为 50 日均线下穿 200 日均线。

**注意：** 均线属于滞后指标，信号出现时趋势可能已进行一段时间。

## MACD 指标

MACD（Moving Average Convergence Divergence，移动平均收敛散度）用于判断趋势的方向和强度。

**组成部分：**
- **DIF 线（快线）**：12 日 EMA - 26 日 EMA
- **DEA 线（慢线）**：DIF 的 9 日 EMA
- **柱状图（Histogram）**：DIF - DEA

**使用方法：**
- DIF 上穿 DEA → 买入信号
- DIF 下穿 DEA → 卖出信号
- 柱状图由负转正 → 趋势转多
- 顶背离（价格创新高但 MACD 不创新高）→ 可能见顶
- 底背离（价格创新低但 MACD 不创新低）→ 可能见底

## RSI 指标

RSI（Relative Strength Index，相对强弱指标）衡量价格变动的速度和幅度，范围 0-100。

**计算公式：**
RSI = 100 - 100 / (1 + RS)
RS = N 日平均上涨幅度 / N 日平均下跌幅度（通常 N=14）

**解读方法：**
- **RSI > 70**：超买区域，可能面临回调。
- **RSI < 30**：超卖区域，可能面临反弹。
- **RSI = 50**：多空平衡点。
- RSI 背离与 MACD 类似，可提示趋势反转。

**局限性：**
- 在强势趋势中，RSI 可能长时间停留在超买或超卖区域。
- 应结合其他指标和价格形态综合判断。

## 布林带（Bollinger Bands）

布林带由三条线组成，用于衡量价格波动性和识别超买超卖。

**三条线：**
- **中轨**：20 日简单移动平均线
- **上轨**：中轨 + 2 倍标准差
- **下轨**：中轨 - 2 倍标准差

**应用方法：**
- 价格触及上轨 → 短期可能偏高（但不一定立即回调）
- 价格触及下轨 → 短期可能偏低
- 布林带收窄（squeeze）→ 波动性降低，可能即将出现大幅波动
- 布林带扩张 → 波动性增大，趋势正在展开

## K线形态

### 基本 K 线
- **阳线（红/绿）**：收盘价高于开盘价，表示上涨。
- **阴线（绿/红）**：收盘价低于开盘价，表示下跌。
- **影线**：上影线表示盘中冲高回落，下影线表示盘中探底回升。

### 经典反转形态
- **锤子线（Hammer）**：长下影线、小实体，出现在下跌趋势底部，预示可能反转向上。
- **倒锤子线（Inverted Hammer）**：长上影线、小实体，出现在下跌底部，可能反弹。
- **吞没形态（Engulfing）**：后一根 K 线实体完全覆盖前一根，看涨吞没或看跌吞没。
- **十字星（Doji）**：开盘价与收盘价几乎相等，表示多空僵持，可能变盘。

## 支撑位与阻力位

- **支撑位（Support）**：价格下跌时倾向于止跌反弹的水平，通常是前期低点、整数关口或重要均线。
- **阻力位（Resistance）**：价格上涨时倾向于受阻回落的水平，通常是前期高点。
- 支撑位被跌破后往往变为阻力位，阻力位被突破后往往变为支撑位，这称为"角色互换"。

## 成交量分析

- **放量上涨**：价格上涨且成交量显著增加，趋势较为可靠。
- **缩量上涨**：价格上涨但成交量萎缩，上涨动力不足。
- **放量下跌**：卖压沉重，趋势可能延续。
- **缩量下跌**：卖压减轻，可能接近底部。
- **天量见天价**：成交量创出极端高值后，价格可能见顶。
