# Contributing

Thanks for your interest in FinAI. This project is open source under the ISC
License, and contributions are welcome.

## Before You Start

- Keep changes focused and easy to review.
- Do not commit API keys, `.env` files, generated caches, model weights, logs,
  or private datasets.
- Respect the terms of any third-party services used by your changes, including
  market data, search, and LLM providers.
- This project is for learning and demonstration. Do not present generated
  analysis as financial advice.

## Development

1. Copy `.env.example` to `.env` and fill in your own keys.
2. Start the backend from `backend/`.
3. Start the frontend from `frontend/`.
4. Run relevant tests before opening a pull request.

## Pull Requests

Please include:

- What changed and why.
- Any setup or migration notes.
- Screenshots for visible UI changes.
- Test results, or a short note explaining why tests were not run.
