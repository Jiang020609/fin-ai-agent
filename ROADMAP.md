# Roadmap

This roadmap focuses on making FinAI more useful as an open-source financial AI
agent demo and a reusable foundation for experiments.

## Near Term

- Add screenshots and a short demo GIF for the streaming chat, chart, and source
  citation flow.
- Add a small example dataset of prompts and expected UI behavior.
- Split the README into a shorter landing page plus deeper architecture docs.
- Add an English README or bilingual quick start.
- Add deployment examples for common cloud platforms.

## Product Ideas

- Portfolio-level analysis across multiple tickers.
- SEC EDGAR and exchange announcement ingestion for earnings-aware answers.
- More asset classes: crypto, FX, commodities, ETFs, and indices.
- Configurable data provider adapters.
- Exportable analysis reports.

## Engineering Ideas

- Redis cache backend for production deployments.
- Optional local embedding model setup.
- Observability dashboard for latency, tool calls, and fallback rates.
- E2E browser tests for the streaming frontend.
- Pluggable agent plans and tool registry.
